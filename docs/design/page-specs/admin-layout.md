## 2. 核心交互区域规格

### 2.1 顶部 Header 沉浸栏
- **左侧折叠开关**：点击切换侧边栏展开 (`width: 220px`) 与收起 (`width: 64px`) 状态。
- **全局租户选择器 (`TenantSelector`)**：
  - 仅对拥有跨租户权限的 `SUPER_ADMIN` 显示下拉选择，普通租户管理员锁定为只读显示当前租户名与配额 Badge。
  - 下拉列表展示：`租户名称`、`设备数/配额 (如 850/1000)`、`租户状态 (正常/即将到期)`。
  - **切换动作**：一旦用户选择新租户，立即更新 `useTenantStore.currentTenantId`，全局所有后续请求自动携带新 `x-tenant-id`，并触发当前激活 Tab 视图的重新加载。
- **消息与告警通知钟 (`AlarmNotificationBell`)**：
  - 接入 WebSocket `alarm.triggered` 事件。
  - 动态显示未读告警红点角标（Badge），点击弹出最近 5 条高危告警抽屉，支持一键直达告警中心处理。
- **个人中心与操作下拉菜单**：
  - 展示当前用户头像、姓名与所属主角色 Tag。
  - 下拉选项：`个人信息`、`修改密码 (弹出 Drawer)`、`退出登录 (二次确认)`。

### 2.2 左侧侧边栏导航 (Sidebar Menu)
- **RBAC 动态过滤**：根据 `useAuthStore.permissions` 自动裁切菜单树，没有对应权限的菜单项完全隐藏，不展示空菜单。
- **分组划分**：
  - 概览看板 (`/dashboard`)
  - 平台中枢 (租户管理 `/tenants`, 机构管理 `/orgs`, 用户管理 `/users`, 角色权限 `/roles`, 项目管理 `/projects`)
  - 资产管理 (设备台账 `/devices`, 车辆档案 `/vehicles`, 物联卡 `/devices/sim`)
  - 车控运营 (车控工作台 `/commands`, 能力配置 `/commands/capabilities`, 数字钥匙 `/keys`)
  - 位置与围栏 (实时定位与轨迹 `/telemetry`, 电子围栏 `/geofence`)
  - 运维保障 (报警中心 `/alarms`, 固件升级 `/ota`, 通讯日志 `/logs`, 运维监控 `/monitor`)

### 2.3 多标签页操作栏 (NavTabs)
- 允许用户同时打开多个业务页面（例如同时打开“设备列表”与“远程车控”），切换时不丢失已填写的搜索条件。
- 标签右键菜单支持：`刷新当前标签`、`关闭当前`、`关闭其他`、`全部关闭`。
- 刷新标签页时保留激活路由状态。

## 3. 验收标准 (Acceptance Criteria)
- [ ] 侧边栏折叠/展开流畅，菜单在刷新页面后能够高亮定位在当前 URL 对应的菜单项；
- [ ] 切换 Header 中的租户后，所有接口自动绑定对应 `x-tenant-id`，页面数据即时切换；
- [ ] 收到实时告警时，顶部铃铛图标数字即时 +1，并有呼吸闪烁动效；
- [ ] 点击退出登录时弹出确认框，确认后清空所有认证与租户状态并平滑重定向至 `/login`。

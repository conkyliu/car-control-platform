> **归属路径**：`docs/design/page-specs/device-management.md`

## 1. 用户目标与典型任务
- **维保工程师**：大批量导入新采购的 500 台 TBox 硬件，查看硬件入网激活状态；对信号异常或客户投诉的设备远程调出参数配置，修改心跳上报频率或 APN。
- **租户管理员**：按项目、在线状态、固件版本、ICCID 筛选检索设备资产台账；查看当前设备配额消耗比。

## 3. 核心子模块与交互规格

### 3.1 设备多维组合筛选区 (Search Toolbar)
- **支持检索项**：
  - 项目归属（下拉多选/单选，从 `GET /api/v1/projects` 获取）
  - 设备状态（Tag 筛选：全部 / 在线 ONLINE / 离线 OFFLINE / 告警 ALARMING）
  - 固件版本号（模糊输入或版本下拉）
  - 关键字快速搜索（支持按设备号 IMEI、ICCID、绑定车牌模糊匹配）
- **操作按钮**：点击“查询”触发带参请求，点击“重置”清空所有筛选项并恢复默认分页。

### 3.2 Excel 批量导入向导 (`BatchImportModal`)
- 点击【批量导入】弹出向导模态框：
  1. **第一步：模板下载**：提供标准 Excel (`.xlsx`) 模版下载链接，包含 IMEI、ICCID、产品型号 ProductKey、预分配机构。
  2. **第二步：拖拽上传与前端预校验**：
     - 前端校验文件类型与行数（单批上限 1,000 行）；
     - 校验 IMEI 是否为合法 15 位数字，ICCID 是否为合法 20 位代码；
     - 比对当前租户剩余配额，若待导入行数超过剩余配额，即时红色告警并阻断上传。
  3. **第三步：调用导入接口与进度反馈**：
     - 调用 `POST /api/v1/devices/batch-import`；
     - 成功后展示“导入成功 495 台，跳过重复项 5 台”，支持一键导出跳过清单。

### 3.3 设备详情抽屉 (`DeviceDetailDrawer`)
- 点击列表行【详情】自右侧滑出抽屉 (`width: 640px`)，分为三大标签页：
  - **Tab 1: 硬件与基础信息**：设备编号、产品型号、批次号、ICCID、运营商、所属机构、激活时间、保修截止期。
  - **Tab 2: 实时工况监控仪表**：
    - 通讯状态：最后心跳时间、当前在线状态 Tag；
    - 信号质量：RSRP、CSQ 指标条形图；
    - 供电监测：主电瓶电压 (V)、备用电池百分比 (%)、芯片运行温度 (°C)；
    - 绑定车辆卡片：车牌号、VIN、车型、车主姓名与联系电话。
  - **Tab 3: 远程参数配置 (Remote Configuration)**：
    - 心跳上报周期（秒，数字输入框，范围 10~3600s）；
    - APN 接入点名称；
    - 蓝牙 PKE 感应开关与灵敏度档位；
    - 远程重启指令（L2 高危确认弹窗）。

## 4. 13 类交互状态处理规范
- **加载态**：表格展示骨架屏加载动画；
- **空数据态**：展示拟人化 Empty 插画，提示“当前项目名下暂无入网设备，可点击上方按钮开始建档”；
- **配额告警**：当租户设备数占用 $\ge 90\%$ 时，在列表顶部展示警告 Banner：“租户设备配额已使用 920/1000，即将达到上限”；
- **异常重试**：网络超时可点击右上角无损刷新按钮重新载入当前页。

## 5. API 契约与事件映射
- `GET /api/v1/devices?page=1&limit=20&keyword=...&status=ONLINE&projectId=...`
- `GET /api/v1/devices/:id`
- `POST /api/v1/devices` (单个建档)
- `POST /api/v1/devices/import` (批量导入)
- `PATCH /api/v1/devices/:id/config` (远程参数下发)
- `WebSocket: device.status` (实时更新单车在线/离线标记)

## 6. 验收标准 (Acceptance Criteria)
- [ ] 能够通过 IMEI、ICCID 或项目下拉组合快速筛选目标设备；
- [ ] 上传 Excel 文件时能够拦截格式错误行与超配额行为；
- [ ] 详情抽屉中能够实时查看设备电瓶电压、4G 信号和心跳时间；
- [ ] 远程下发心跳参数后，能够捕获终端 ACK 并更新参数生效状态。

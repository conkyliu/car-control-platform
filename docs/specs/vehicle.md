# Vehicle Domain Specification (车辆与车型规范)

## 1. 业务目标
负责车辆档案、品牌与车型关联、软硬件绑定关系建立与解除、车辆状态管理。

## 2. 车辆唯一性与模型属性
- `vin` (车架号): 17 位国际标准唯一识别码，全平台全局唯一。
- `plateNumber` (车牌号): 如 `粤B12345`。
- `brandId` / `modelId`: 关联品牌与车型能力模板（如是否具备远程点火、电动尾门、车窗控制）。
- `deviceId`: 当前绑定的 TBox 设备 ID（1 辆车最多绑定 1 台有效设备）。
- `status`:
  - `NORMAL`: 正常运营中
  - `MAINTENANCE`: 维保检修中
  - `LOCKED`: 运营方风控锁死（禁止下发部分控制指令）
  - `SCRAPPED`: 已报废

## 3. 软硬件绑定与换件解绑业务流
1. **绑定约束**：
   - 目标车辆和目标设备必须属于**同一个租户**（严禁跨租户绑定）。
   - 目标设备当前未被其他车辆占用（若已被占用，必须先解绑旧车）。
   - 目标车辆当前未绑定其他设备（若已有设备，需先解绑或替换）。
2. **解绑流程**：
   - 将 `vehicle.deviceId` 置空，保留历史操作记录与通信审计日志。
   - 设备恢复为独立未绑定状态。

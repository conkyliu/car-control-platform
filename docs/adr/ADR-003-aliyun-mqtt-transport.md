# ADR-003: 默认采用阿里云 IoT MQTT 作为车载通信传输层

## 背景
TBox 设备通信具有长连接、高并发上行与低延时下发特点。云平台需要稳定、高可用且经受海量设备检验的物联网接入网关。

## 决策
1. 默认采用阿里云 IoT MQTT 作为设备接入标准协议通道；
2. 抽象统一的 `MessagingPort` 接口，使核心 `CommandDomain` 与具体云厂商 SDK 解耦；
3. 对于私有二进制/TCP 协议设备，通过前置网关适配为统一的消息通道，严禁私有编码渗透进入核心业务域；
4. 函数计算（FC）与规则引擎不进入核心控车下行路径，NestJS 直接调用 IoT Publish 直通下发。

## 结果
- 降低自建海量 MQTT Broker 的运维风险；
- 保持领域模型整洁，便于在测试与本地开发时切换为轻量级 Mock / 本地 Broker。

# ADR-008: 远程控车三级安全分级防御机制

## 背景
控车指令具备不同的物理影响和危害半径：
- 闭锁、寻车几乎无安全和法律风险；
- 解锁可能导致车内物品失窃；
- 远程点火或熄火若在封闭车库或行驶中误触发，可能引发严重人身伤亡。

## 决策
1. 划分 L0、L1、L2 三个不可逾越的安全等级；
2. 服务端在执行控车前强制校验等级要求：
   - L1 检查用户预设的 6 位独立控车安全码；
   - L2 检查一次性短期强确认 Token (`confirmationToken`)；
3. 增加指令级 Rate Limiting 频次限流，杜绝连击和高频攻击；
4. 任何安全等级验证失败，一律记录带有完整追踪信息的审计告警，并返回标准 HTTP 403 / 429。

## 结果
- 建立从常规操作到高危控制的多层纵深防御体系。

# ADR-010: 双 Token (Access & Refresh) 鉴权机制

## 背景
控车平台需要极高的指令响应速度（P95 <= 2s）。如果每次 API 调用都要去中心化数据库/Redis 检索会话，高频指令下发时会造成性能瓶颈；而如果直接使用长期有效的无状态 JWT，一旦密钥或 Token 泄露，无法及时撤销。

## 决策
采用双 Token 架构：
1. **短生命周期 Access Token (15 分钟)**：无状态验签，携带必要的用户与权限信息，业务接口无需查库即可快速鉴权。
2. **长生命周期 Refresh Token (7 天)**：支持服务端轮换与主动吊销。当 Access Token 过期时，客户端通过专门的刷新端点安全换取新 Token 对。
3. 关键敏感指令（如 L2 级远程发动机启动、熄火）在 Access Token 校验通过的基础上，增加二次身份验证（安全码）。

## 结果
- 兼顾业务接口极速响应与敏感会话可控可撤销的高安全要求。

# ADR-009: 多租户隔离安全架构设计

## 背景
控车平台作为多租户 SaaS 系统，不同客户（汽车厂商、车队、租赁公司）拥有独立的车辆、设备、行车轨迹与控制权限。任何跨租户数据泄露或越权控车均属于毁灭性安全事故。

## 决策
1. 采用单库共享 Schema、按 `tenant_id` 字段行级隔离方案；
2. 建立三层隔离防线：
   - 第一层：HTTP 拦截层，从校验合法的 JWT 中提取 `tenantId` 注入 `TenantContext`（基于 Node.js `AsyncLocalStorage`）；
   - 第二层：领域服务与 Repository 层，所有业务查询与写入强制带入当前上下文 `tenantId`；
   - 第三层：E2E 自动化测试用例强制覆盖跨租户查询、跨租户更新与跨租户删除场景。
3. 严格禁止仅依赖已废弃的 Prisma 旧 Middleware 全局自动拦截作为唯一安全防线。

## 结果
- 保证租户数据隔离具备确定性与可审计性；
- 避免因某处查询遗漏租户过滤导致越权漏洞。
